# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good intent, and keep discussions focused on the work. Harassment or personal attacks of any kind are not tolerated.

To report unacceptable behaviour, contact the maintainer through GitHub ([@mk-quantlabs](https://github.com/mk-quantlabs)). Reports are handled privately.
